SKU Inventori
- Saat menambah barang, kosongkan kolom SKU untuk membuat SKU-000001, SKU-000002, dan seterusnya berdasarkan SKU yang sudah terlihat pada workspace.
- Kamu juga bisa mengetik SKU manual; aplikasi memeriksa duplikat di daftar yang dimuat.
- Migrasi SQL menambahkan unique index per tenant sebagai perlindungan database. Jika ada SKU duplikat lama, migrasi akan gagal sampai duplikat dibereskan.

Admin platform
- Tabel platform_owners dan platform_activation_codes sudah disiapkan pada proyek Supabase oleh pemilik.
- Jangan memberi akses tabel tersebut langsung ke browser. Aktivasi langsung dan penukaran kode belum aktif sampai server-side Edge Functions dibuat dan diterapkan.
- Jangan menyimpan service_role key di file .env frontend atau membagikannya.
- Jangan menganggap menu admin sudah aktif hanya karena tabel ada.
